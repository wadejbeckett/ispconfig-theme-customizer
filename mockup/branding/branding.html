Mark for light backgrounds

?

The mark that sits on a light background, so it should be dark or full-colour. This is the one ISPConfig itself uses: the stock header and the login page are both light. Choose a file, then press Upload — the logo uploads on its own, separately from Save changes.

Drop a file here or choose one. SVG, PNG, JPEG, GIF or WebP, under 45 KB.

Optional, and it wins over the uploaded file. A root-relative path (recommended — /themes/custom/logo.svg) or an https:// URL. SVG or a 2× PNG around 500×160 works best. A remote URL ties your login page to that host and reveals visitor IPs to it — prefer a local path.

Mark for dark backgrounds

The light or white version. Clarity's sidebar and login band use this one. Same formats and the same 45 KB limit. It is kept in the interface settings rather than in a logo column of its own, so it is re-read on page loads and written into the change log the next time you save — use the path field below if that matters on your panel.

Placement

?

Automatic reads the colour you set for that surface and picks the mark that stays readable on it. One setting, obeyed by every design you have installed — change it only if a colour you set makes the automatic choice wrong. A slot you have not filled still borrows from the other one.

Panel visibility
?

The Design drop-down under Tools > User Settings, where a user picks the panel design. Hiding it applies to every role — including you, so switch it back on here when you need to change design. A crafted request can still change the theme, so this is cosmetic and not enforcement.

?

The "About ISPConfig" section and the version line under Help. Hiding it applies to every admin, including you, so demos stay clean. A brand-aware design hides it visually; the page itself stays reachable by direct URL.

?

The "Latest news" sidebar on the dashboard. Turning it off hides it for every role; turning it back on restores the default feed but keeps any custom feed URLs you set under System > Interface Config. Users see the change at their next login.

The donation appeal ISPConfig places at the top of the dashboard. Only administrators ever see it — never resellers or clients — so this is about your own dashboard. It writes the same setting ISPConfig's own Hide button writes, except that this one does not expire after a year.
